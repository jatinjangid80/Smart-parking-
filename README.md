# 🚗 Smart Parking System

An **IoT + AI-powered Smart Parking System** that provides real-time parking availability, slot booking, smart parking predictions, digital payments, and live monitoring.

> **Find. Reserve. Park. Pay. Predict.**

---

### 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, TanStack Query
- **Backend:** Node.js, Express, tRPC
- **Database & Storage:** Drizzle ORM, AWS S3
- **IoT & AI (Extended):** ESP32, Python AI/ML, Socket.io, Redis

---

### 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   pnpm install
   ```

2. **Start dev server:**
   ```bash
   pnpm run dev
   ```

3. **Build for production:**
   ```bash
   pnpm run build
   ```
